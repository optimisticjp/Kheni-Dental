# Public assets

Add final clinic assets here during the polish round.

Suggested structure:

- `brand/` logo and approved brand files
- `images/doctors/` professional doctor portraits
- `images/locations/` Yogi Chowk and Hirabaug clinic photography
- `images/cases/` patient-approved before and after cases
- `images/technology/` verified equipment and treatment-room photography

Use descriptive filenames, responsive image sizing and meaningful alt text. Do not add patient-identifiable case imagery without documented consent.

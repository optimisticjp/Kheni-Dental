# Content & Asset Checklist for Kheni Elite

Do not ask the doctor for design choices. Ask only for facts, source material and approvals that only the clinic can provide.

## Brand & contact
- [ ] Official legal/public clinic name
- [ ] Highest-quality logo file available
- [ ] Exact verified address
- [ ] Google Maps URL
- [ ] Main phone number
- [ ] WhatsApp number
- [ ] Email address
- [ ] Verified working hours
- [ ] Instagram / Facebook / YouTube links
- [ ] Number of active clinic locations

## Doctor profiles
For every doctor:
- [ ] Full name
- [ ] Exact qualifications
- [ ] Registered specialties
- [ ] Education / training
- [ ] Years of experience if the doctor wants it published
- [ ] Professional memberships
- [ ] Certifications
- [ ] Clinical focus
- [ ] Languages spoken
- [ ] Awards only if verifiable
- [ ] High-resolution portrait
- [ ] Short approved biography

## Treatments
- [ ] Full treatment list
- [ ] Priority treatments for marketing
- [ ] Treatments offered only by specialists
- [ ] Any technologies/materials the clinic wants mentioned
- [ ] Clinician-approved FAQs
- [ ] Clinician-approved treatment process summaries
- [ ] Any financing/EMI information if applicable

## Clinic proof
- [ ] Verified Google rating at launch
- [ ] Verified review count at launch
- [ ] Verified founding year
- [ ] Verified years in practice
- [ ] Verified case/implant count only if the clinic can substantiate it
- [ ] Accreditations
- [ ] Awards
- [ ] Technology/equipment list
- [ ] Sterilisation workflow the clinic is comfortable publishing

## Photography/video
- [ ] Lead doctor hero portrait
- [ ] All doctor portraits
- [ ] Reception
- [ ] Treatment rooms
- [ ] Exterior / signage
- [ ] Team
- [ ] Consultation in progress
- [ ] Equipment / technology
- [ ] Detail shots for premium design sections
- [ ] International/NRI welcome imagery if genuine

## Patient proof
- [ ] Selected genuine Google reviews
- [ ] Patient testimonial permissions
- [ ] Before/after cases with appropriate consent
- [ ] Case description approved by treating doctor
- [ ] Any patient video testimonials

## International / NRI patients
- [ ] Does the clinic actually have NRI/international patient experience?
- [ ] Countries patients commonly travel from
- [ ] Languages supported
- [ ] Remote pre-arrival consultation/coordination process
- [ ] What records can be reviewed before travel and through which private channel
- [ ] Airport / transport guidance actually offered
- [ ] Hotel/accommodation guidance actually offered
- [ ] Typical appointment sequencing by treatment category, only if clinicians approve
- [ ] Follow-up process after the patient leaves India

## Patient resources
- [ ] First-visit instructions
- [ ] Implant aftercare
- [ ] Root-canal aftercare
- [ ] Wisdom-tooth aftercare
- [ ] Orthodontic/aligner care
- [ ] Oral hygiene guide
- [ ] Existing brochures/PDFs

## Launch approvals
- [ ] Privacy policy
- [ ] Terms / medical disclaimer
- [ ] Photo/case consent process
- [ ] Final review of all medical claims by clinic
